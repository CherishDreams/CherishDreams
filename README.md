## 精选项目 / Featured Projects

### [atri-editor](https://github.com/CherishDreams/atri-editor)

基于 Tiptap v3 的框架无关富文本编辑器，支持 Web Component、Markdown 双向转换、AI 集成与图片/附件上传；已发布 npm 包 `@atri-editor/core`。

<sub>A framework-agnostic rich text editor built on Tiptap v3, with Web Component support, Markdown round-trip, AI integration, and media upload. Published on npm as <code>@atri-editor/core</code>.</sub>

`TypeScript` `Tiptap` `Web Component` `Vite` `Vitest`

### [atri-bot](https://github.com/CherishDreams/atri-bot)

可扩展的 Agent 平台，采用 Node.js/TypeScript 服务端与 Vue 3 控制台；支持多模型 Provider、工具调用、MCP 服务器、技能、记忆、主动消息与聊天平台适配。

<sub>An extensible agent platform with a Node.js/TypeScript server and a Vue 3 dashboard. Supports multiple model providers, tool calling, MCP servers, skills, memory, proactive messaging, and chat-platform adapters.</sub>

`TypeScript` `Node.js` `Vue 3` `SQLite` `MCP`
